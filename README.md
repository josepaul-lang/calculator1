# 💀 THE SARCASTIC CALCULATOR 🔥
> **"Math is easy. Your dignity is optional."**

Welcome to **The Sarcastic Calculator** — a modern, dark-cyberpunk, roast-fueled web application that performs 100% mathematically correct calculations while ruthlessly roasting the user for asking for help with simple math.

---

## 🌟 Key Features

### 1. 🧮 100% Mathematically Accurate & Safe Engine
- Built with Dijkstra's **Shunting-Yard algorithm** and **Reverse Polish Notation (RPN)** evaluation.
- **Zero usage of `eval()`** — completely safe from arbitrary code execution.
- Handles full order of operations (PEMDAS), brackets `()`, percentages `%`, decimals, negative numbers, and chained expressions.
- Full keyboard support: Enter numbers, operators (`+`, `-`, `*`, `/`), parentheses, `Enter` or `=` to evaluate, `Backspace`, and `Escape` / `C` to clear.
- Results copying to clipboard with one click.
- Persistent calculation history with load-back support.

### 2. 🔥 Context-Aware Roast Engine (100+ Unique Roasts)
- Context-aware intelligence tailored to what you calculate:
  - **Baby Math** (e.g. `2 + 2`, `5 - 3`): Roasts you for summoning an entire computer for toddler arithmetic.
  - **Zero Brainers** (e.g. `10 * 10`, `100 + 100`): Roasts for moving decimals.
  - **Halving** (e.g. `50 / 2`): Recommends cutting a pizza instead of using digital hardware.
  - **Divide by Zero** (e.g. `50 / 0`): Triggers a galactic singularity warning & dramatic paradox reactions.
  - **Equal Spammer**: Catches when you repeatedly mash `=` expecting your bank account to rise.
  - **Complex Math**: Gives sarcastic applause to "Mr. Oppenheimer" for using brackets.
  - **Syntax Errors**: Hilarious roasts for mismatched brackets or gibberish.
  - **Easter Eggs**: Secret funny reactions for `69`, `420`, `80085`, `1337`, `666`, `777`, `911`.
- **4 Intensity Levels**:
  1. *Friendly (Mercy Mode 😇)*
  2. *Sarcastic 😏*
  3. *Savage 💀* (Default)
  4. *Absolutely Unhinged 🔥*
  5. *Mute Roasts 🏳️*

### 3. 🎨 Animated Meme Reaction Canvas Engine
- Built-in dynamic HTML5 Canvas meme rendering engine:
  - **Bruh Skull Facepalm**: Glowing red flame eyes and comic facepalm slap.
  - **Black Hole Singularity**: Swirling particle accretion disk with an event horizon for divide-by-zero.
  - **Ascended Galaxy Brain**: Radiating cosmic beams and floating calculus symbols.
  - **Clown Certified**: Squeaky clown nose and makeup for silly errors.
  - **Dumpster Fire**: Flickering flames for syntax trainwrecks.
  - **Wheezing Laugh**: Tear-streaming classic reaction face.
  - **Confetti Party Trophy**: For solving complex formulas.
- Guaranteed 100% uptime with zero external link decay or third-party copyright issues.

### 4. 🔊 Built-in Web Audio API Synthesizers
- Custom procedural sound effects generated natively in the browser:
  - `Bruh` trombone slide
  - `Fail Wah-Wah-Waaah` trumpet pattern
  - `Explosion` noise filter drop for dividing by zero
  - `Airhorn` triple blast for Easter eggs
  - `Dramatic Boom` 808 sub-bass drop
  - `Victory Fanfare` 8-bit melody
  - `Snicker` chuckling frequency pulses
  - `Sad Violin` slide
  - Tactile key clicks
- Full volume slider and instant mute toggle.

## 🚀 How to Run Locally

### Option A: Using Python (Installed & Ready)
Run this command in the project directory:
```bash
py -m http.server 8080
```
Then open your browser and navigate to:
```
http://localhost:8080
```

### Option B: Direct File Open
You can also simply double-click [index.html](file:///d:/Calculator%20sample/index.html) or open it with any modern web browser (Chrome, Edge, Firefox, Brave, Safari).
